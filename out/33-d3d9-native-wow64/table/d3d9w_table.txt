# Spec 33 F1: d3d9w_table, the 15 interfaces of the Direct3D 9 frontend with every method in
# vtable order (Wine 11.4 include/d3d9.h). tools/gen_d3d9w.py reads this file, checks it against
# the header and writes gen/.
#
#   interface <name in d3d9.h> <kind>
#   <method> <return> [<argument>...] [@guest] [@special=<helper>]
#
# The kind numbers the interface in method ids (IOS_WOW_NATIVE_ID(1, id)): kinds 0-14 in the
# order of this file, 15 for the exports and the thunk's extra calls (gen/d3d9w_ids.h).
#
# Returns: hr (HRESULT), u32 (ULONG, UINT, DWORD, BOOL or an enum), count (a UINT count: 0 when a
# program pointer is refused), void, float (bits in EAX, spec 33 clarification 3), handle
# (HMONITOR, truncated to its 32-bit value).
#
# Arguments (every one is 4 bytes on the i386 stack):
#   v              a 32-bit value (integer, BOOL, enum, D3DCOLOR or float), passed as it is
#   h              a handle (HWND): the same 32-bit number on both sides
#   opaque         a pointer native code never dereferences (RegisterSoftwareDevice)
#   in:T           pointer to one T, copied in; NULL stays NULL
#   out:T          pointer to one T, copied in and written back (untouched stays untouched)
#   inout:T        as out:T; the name says the method reads it
#   in:T[n]        n elements: a number, aK (argument K, 1-based after This) or M*aK
#   in:T[*]        a length only the special helper knows
#   hout:T         pointer to one handle T, written back as its 32-bit value
#   iid            a REFIID/REFGUID, 16 bytes copied in
#   if:K           an interface pointer in: a proxy of kind K (or of a kind K stands for)
#   ifout:K        pointer to an interface out: the proxy of the object native code returns
#   ifout_iid      as ifout, of the kind the preceding iid names (QueryInterface, GetContainer)
#   ifarr:K[n]     an array of n interface pointers in
#   shader         shader tokens up to the end token (F3)
#   decl           D3DVERTEXELEMENT9 array up to D3DDECL_END (F3)
#   rgn            an optional RGNDATA: header plus nCount rectangles (F3)
#   shared         HANDLE*: the D3D9Ex user-memory pointer or a share handle, read only (C3)
#   lockptr        void** a Lock returns: a guest address of window memory (F5)
#
# Kinds K for if/ifout: D3D9 Device SwapChain Surface Texture CubeTexture VolumeTexture Volume
# VertexBuffer IndexBuffer VertexDecl VertexShader PixelShader StateBlock Query, and the
# families BaseTexture (the three texture kinds) and Resource (surface, textures, volume,
# buffers).
#
# @guest: the thunk's vtable holds a hand-written guest function (spec 33 E3, clarification 7);
#         the generated stub stays reachable for that function's own native calls.
# @special=<helper>: the dispatch calls a hand-written helper (native/d3d9w_special.c) after the
#         arguments are read and This is resolved.
